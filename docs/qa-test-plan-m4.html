Smiles Craft Mobile — Test Guide

What to check in this build: Cashier & Reports, plus the fixes from the last feedback round.

Build: Milestone 4 preview (Cashier, Reports & Feedback Fixes)
App version: 1.3.0  ·  Platform: Android app file (APK)
Prepared: 3 July 2026
Environment: Connected to the live system — records you create here appear on the web app too.

1. Before you start

  1. Install the app file (the APK) from the link shared with you. If Android warns about installing outside the Play Store, allow it for this file.
  2. Sign in with your Smiles Craft clinic account — the same email and password you use on the web app.
  3. Use a real (or clearly-labelled test) patient. Because the app is connected to the live system, anything you register, book, or charge is saved and will also show on the web app. If you want to experiment freely, create a patient named e.g. "Test Patient" so it is easy to spot and remove later.
  4. Best on a real phone — your own phone is ideal. Notifications and the calendar gestures behave most realistically there.
How to record your feedback. For anything that looks wrong, please note four things so it can be reproduced quickly: (1) the screen, (2) the exact steps you took, (3) what you expected, (4) what actually happened — plus a screenshot if possible. There is a blank feedback table at the end of this guide you can fill in.

These are the areas that changed since your last review — worth focusing on first. Tags: NEW a new feature, FIX something corrected, COMING SOON full behaviour arrives in an upcoming update.
