1. Before you start

  1. Install the new app file (the APK) from the link shared with you. If Android warns about installing outside the Play Store, allow it for this file. If the update won't install over the old one, uninstall the previous app first — your data is on the server, so nothing is lost.
  2. Confirm the version. Open Profile and check it reads v1.4.0, so you know you are testing this build.
  3. Sign in with your Smiles Craft clinic account — the same email and password you use on the web app.
  4. A few checks need a two-doctor clinic (marked below). Use an account whose clinic has more than one doctor for those — for example the two-doctor login you used last time.
  5. One check needs a non-dental specialty (Treatment & Orders). Use a physiotherapy — or other non-dental — account for that row.
How to record your results. Mark each row Pass or Fail. For anything still wrong, please note (1) the screen, (2) the exact steps, (3) what you expected, (4) what actually happened — plus a screenshot if possible. There is a blank feedback table at the end.
